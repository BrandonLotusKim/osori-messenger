# ConversationWindow 디자인 스펙 (OC-D03)

> 1:1 대화와 그룹방을 **하나의 창 타입**으로 처리. MainWindow 의 대화 리스트에서
> 아이템을 더블클릭하거나 조직도 멤버를 더블클릭하면 열린다.
> 여러 대화창을 동시에 띄울 수 있고 각 창은 상대/방 단위로 하나씩.

---

## 1. 목적

- 메시지 스트림 읽기·쓰기 기본 경로.
- 파일 첨부/수신/다운로드 인라인 처리.
- 1:1 vs 그룹방은 **모드 스위치** 로 같은 창이 동작만 달리함.
- 스크롤 위치·히스토리 페이지네이션 자연스럽게.

## 3. 메시지 말풍선 스펙

| 요소 | 내 메시지 | 상대 메시지 |
|---|---|---|
| 정렬 | 우측 | 좌측 |
| 말풍선 배경 | `#DCF8C6` (카톡 유사 연녹) | `#FFFFFF` (흰색) + 1px 테두리 |
| 최대 너비 | 창 너비의 70% | 창 너비의 70% |
| 꼬리 | 없음 (심플) | 없음 |
| 모서리 | 12px | 12px |
| 내부 패딩 | `10 12` | `10 12` |
| 시각 표시 | 말풍선 좌측 하단 옆 | 말풍선 우측 하단 옆 |
| 상태 배지 | 시각 옆 (⏳✓!📮) | 없음 |
| 발신자 이름 | 생략 | 그룹방일 때만 말풍선 위에 표시 |
| 아바타 | 생략 | 그룹방에서만 좌측에 표시 (이니셜 원) |

**연속 메시지 그룹핑**: 같은 발신자가 2분 이내 연속 보내면 두 번째부터 이름/아바타 생략.

### 상태 배지

| 배지 | 의미 | 색 |
|---|---|---|
| ⏳ | Sending (서버 ack 대기) | `#9E9E9E` |
| ✓ | Delivered (서버 수신) | `#4CAF50` |
| ✓✓ | Read (상대가 읽음) | `#2196F3` *(후속 — 서버 read receipt 필요)* |
| 📮 | Queued (오프라인 수신자, outbox 저장) | `#FFA726` |
| ⚠ | Failed (재시도 한계) | `#E53935` |
| 🚫 | Invalid target / Rate limited | `#E53935` |

## 4. 특수 메시지 유형

### 4.1 파일 첨부 (수신)
`
┌─────────────────────────────────────┐
│ 📎 배포계획_v2.pdf                  │
│ 1.2 MB · application/pdf            │
│ [다운로드]  [저장 폴더 열기]        │
└─────────────────────────────────────┘
`
- 파일 아이콘은 확장자별 (pdf/docx/xlsx/png/zip/기타)
- 다운로드 클릭 → 진행률 오버레이:
  `
  [█████████░░░░░░] 58%  (710 KB / 1.2 MB)
  `
- 완료 시 `[저장 폴더 열기]` 활성화, 파일 탐색기에서 해당 파일 선택 표시

### 4.2 파일 첨부 (송신)
- 첨부 모드: 입력 영역 하단에 "첨부 파일" preview, `[×]` 로 취소 가능
- 전송 시 본문 텍스트 + 파일 둘 다 있으면 **2개 메시지로 분리** (텍스트 먼저, 파일 뒤)
- 업로드 중인 메시지:
  `
  ┌─────────────────────────────────────┐
  │ 📎 설계서.pdf                       │
  │ [████████░░░░░] 65% (2.1/3.2MB)    │
  │ [취소]                              │
  └─────────────────────────────────────┘
  `
- 완료 시 ✓ 배지 + 저장소 경로 표시

### 4.3 시스템 메시지
- 날짜 구분선 `───── 오늘 ─────`
- 그룹방 이벤트 (후속):
  - `alice 님이 charlie 님을 초대했습니다.`
  - `bob 님이 방을 나갔습니다.`
- 글자색 `#9E9E9E`, 중앙 정렬, 말풍선 없음

### 4.4 링크 프리뷰 (후속)
- http(s) URL 감지 시 자동 미리보기 카드 (OpenGraph) — 이번 스펙 out

## 5. 상호작용 상태

| 상태 | 설명 | UI |
|---|---|---|
| **Opening** | 창 생성 직후 | 로딩 스피너 + "메시지 불러오는 중..." |
| **Loaded** | 히스토리 pull 완료 | 맨 아래로 스크롤 + 포커스 입력 |
| **Typing** | 입력 중 | (상대 typing 인디케이터 = 후속) |
| **Sending** | Enter 누름 | 낙관적 UI — 말풍선 즉시 표시 ⏳ → ack 도착 시 ✓ |
| **SendFailed** | Ack 실패/타임아웃 | ⚠ 배지 + 우클릭 → 재전송 |
| **Receiving** | 새 메시지 수신 | 스크롤이 맨 아래면 자동 따라감. 위에 있으면 **플로팅 배지** 로 "새 메시지 ↓" |
| **Paginating** | 맨 위로 스크롤 | 상단에 로딩 스피너, 과거 50건 pull 후 현재 스크롤 위치 유지 |
| **RoomLeft** | 나가기 | 창 자동 닫기 + MainWindow 리스트에서 제거 |

---

## 6. 스크롤 규칙

- **초기 로드**: 최신 50건 + 맨 아래로 스크롤
- **페이지네이션**: 맨 위에서 50px 이내면 이전 50건 pull, 로드 후 "기준 메시지" 위치 유지 (사용자 시점 보존)
- **새 메시지 수신**:
  - 스크롤이 맨 아래에서 100px 이내 → 자동 따라가기
  - 그 외 → 화면 하단에 "새 메시지 3건 ↓" 배지 표시, 클릭 시 맨 아래로 스크롤
- **날짜 헤더**: 스크롤 도중 현재 시점 날짜를 sticky 로 상단 표시 (구현 복잡하면 인라인만)

## 8. 입력 영역 상세

- `TextBox` multiline, 최소 1줄 ~ 최대 6줄 자동 확장
- `Enter` = 전송 / `Shift+Enter` = 새 줄
- 빈 텍스트 + 첨부 없음 = 전송 버튼 비활성
- `Ctrl+U` 또는 📎 클릭 → 파일 선택 모달 (32MB 제한)
- `Ctrl+V` 이미지 클립보드 붙여넣기 → PNG 로 첨부 변환 (후속)
- 이모지 피커 (후속)

---

## 9. 창 관리 규칙

- **같은 상대/방엔 창 하나**: MainWindow 가 `Dictionary<conversationKey, ConversationWindow>` 유지. 이미 열려있으면 `Activate` + flash
- **창 위치 기억**: 마지막으로 닫은 위치·크기를 **대화별이 아니라 전역 하나**로 SettingsStore 에 보존 (`ConversationWindowBounds`)
- **포커스 시 읽음 처리**: 창이 Active 상태일 때 수신된 메시지는 unreadCount 증가 안 함. 창이 숨겨져 있거나 포커스 없으면 카운트
- **창 닫기 ≠ 방 나가기**: 그룹방에서 창 닫아도 서버 상태는 유지, 재오픈하면 계속 수신
- **Alt+F4 / 닫기 버튼**: 그냥 닫기. 방 나가기는 ⋮ 메뉴로만.

## 13. 구현 영향 범위

**신규/수정**:
- `ConversationWindow.xaml` / `.xaml.cs` (신규 — 기존 ChatWindow 의 중앙 영역 로직 이식 + 대폭 재구성)
- `MessageBubble.xaml` UserControl (신규) — 내/상대 모드, 파일 첨부 렌더
- `MemberDrawer.xaml` UserControl (신규)
- `AttachmentPreview.xaml` UserControl (신규, 업로드 중/완료)
- `DateSeparator.xaml` (신규, 작은 UserControl)
- `ConversationMode` enum (DirectMessage / Room)
- MainWindow 쪽 열기 로직:
  - `OpenConversationAsync(key, mode)` — 중복 방지 Dictionary 관리
- `MessengerClient`:
  - 기존 API 재사용
  - `GetRoomHistoryAsync(roomId, since, limit)` (신규 — 서버에 방별 히스토리 API 추가 필요, OC-D03-impl 에서 함께 설계)
- `ConversationViewModel` (신규, MVVM 으로 리팩터링 검토 — 현재 code-behind 방식이 빠르면 그대로 유지)

**서버 측 후속 필요 항목**:
- 방별 히스토리 API (`RoomHistoryRequest` / `Response` — 현재 1:1 HistoryRequest 만 있음)
- @mention 파싱 (후속)

## 14. Out of scope

- 타이핑 인디케이터 (상대가 입력 중 표시)
- Read receipt (읽음 ✓✓)
- @mention 파싱/하이라이트 + 알림
- 링크 프리뷰(OpenGraph)
- 이모지 피커 / 이미지 인라인 뷰어 / 스티커
- 메시지 수정·삭제 (서버 모델 없음)
- 답글(reply-to) 인용
- 음성/영상 통화
- 클립보드 이미지 붙여넣기
- 드래그앤드롭 파일 첨부 (1차 구현은 파일 다이얼로그만)
